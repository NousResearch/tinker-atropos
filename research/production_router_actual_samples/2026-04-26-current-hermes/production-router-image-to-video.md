# 이미지 영상 요청 라우팅 실제 샘플

작업분류: 지피티 이미지 투 이미지 생성에서 럽아트 시댄스 영상 실험까지 이어지는 제작 운영 작업이다.
선행경로: openai-codex-gpt-image-2-workflow로 지피티 이미지 투 프롬프트와 결과 파일 존재를 먼저 확인한다.
실행표면: 이미지 생성 뒤 럽아트에서 시댄스 이점영 영상 변형을 만들고 기준군과 변형을 비교한다.
산출물: 이미지 파일, 영상 링크, 프롬프트, 점수표를 남긴다.
검증: 파일 존재, 크기, 시각 확인, 점수표 결과를 확인한다.
기록: 학습 질문, 기준군, 변형, 유지할 것, 버릴 것, 다음 변수를 옵시디언과 스킬에 기록한다.
