# 웹사이트 제작 요청 라우팅 실제 샘플

작업분류: 웹사이트 랜딩페이지 제작, 디자인 계약, 이미지 생성, 코드 구현, 브라우저 검증이 함께 필요한 제작 운영 작업이다.
선행경로: 먼저 알피 씨엘아이로 저장소 루트와 관련 파일을 확인한다. 피그마가 있으면 figma-use로 디자인 문맥과 스크린샷을 확보하고, DESIGN.md를 디자인 계약서로 읽어 토큰과 드리프트를 확인한다.
실행표면: 헤르메스가 수락 기준을 세우고 필요하면 코덱스 씨엘아이로 구현을 맡긴다. 지피티 이미지 투 이미지는 openai-codex-gpt-image-2-workflow로 만든다.
산출물: 변경 파일, DESIGN.md 드리프트 메모, 이미지 파일 경로, 프롬프트 로그, 브라우저 스크린샷을 남긴다.
검증: 빌드, 테스트, 브라우저 검증, 이미지 파일 존재 확인을 실행하고 결과를 완료 보고에 적는다.
기록: 성공 규칙과 실패 패턴을 옵시디언 노트와 티커 아트로포스 평가 세트에 기록한다.
