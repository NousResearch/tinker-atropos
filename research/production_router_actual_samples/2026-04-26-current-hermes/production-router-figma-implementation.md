# 피그마 구현 요청 라우팅 실제 샘플

작업분류: 피그마 기준 웹 앱 화면 구현과 디자인 시스템 정렬 작업이다.
선행경로: figma-use로 디자인 문맥과 스크린샷을 확보하고 DESIGN.md 디자인 계약서를 먼저 읽는다.
실행표면: 토큰과 컴포넌트 기준으로 코드 반영을 진행하고 구현 과정에서 피그마와 DESIGN.md를 함께 본다.
산출물: 스크린샷, 노드 정보, 드리프트 로그, 변경 파일, DESIGN.md 메모를 남긴다.
검증: 브라우저 화면 비교, 린트, 빌드, 드리프트 확인을 실행한다.
기록: 옵시디언 노트와 스킬에 디자인 계약 기준과 실패 패턴을 기록한다.
