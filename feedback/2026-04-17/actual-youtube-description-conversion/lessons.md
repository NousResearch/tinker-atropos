# Lessons

## 무엇이 먹혔는가
- 유튜브 설명란에서 텔레그램 체크리스트 합류로 잇는 랜딩 카피
- 첫 주 체크인 한 가지와 자기소개 한 줄을 붙인 유지 문장
- 설명란 첫 문장과 CTA를 같이 보는 행동 문장

## 무엇이 덜 먹혔는가
- X 단계는 아직 다른 단계만큼 높지 않다

## 다음 번 자동 생성에서 강화할 포인트
- 설명란과 이어지는 행동 문장
- 텔레그램 체크리스트 합류 헤드라인
- 첫 주 발화율 중심 유지 문장

## 다음 번 자동 생성에서 감점할 포인트
- 설명란 상담 CTA만 반복하는 일반 랜딩
- 장황한 체크인 문구
- 합류 이유가 약한 카피
